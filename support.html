Help for Saber Wallet

Before you ask

  • Never share your recovery phrase or private key. Saber support never asks for them. Any person who asks for them is a scammer.
  • Read the FAQ.

Common problems

  • Balances do not load. Select the refresh button in the wallet. Free public services can be slow. Add a free RPC key in Settings → Solana network for faster data.
  • A swap is blocked. Saber blocks a transaction if the simulation shows that it takes more than the swap amount, or that it fails. Get a new quote and try again.
  • Perps activation fails. The account needs about 0.028 SOL for the Phoenix account rent and the fee.
  • I forgot my password. Select "Forgot password? Import with recovery phrase" on the unlock screen, and import the phrase again with a new password.

Report a problem

Open an issue in the Saber Wallet GitHub project. Tell us the Saber version, the browser, the steps, and what you saw. Do not include keys, recovery phrases, or passwords.

Security problems

If you find a security problem, open an issue with the title "Security" and no details. We then contact you for the details.
