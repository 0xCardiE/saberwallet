# Saber Wallet website

This repository contains the website of Saber Wallet, a self-custody Solana wallet for Chrome. GitHub Pages publishes the website.

The website has these pages:

- `index.html`: the home page (features, security, questions, install)
- `privacy.html`: the privacy policy
- `terms.html`: the terms of use
- `support.html`: help and problem reports

The website is static HTML and CSS. It does not need a build step. To see it on your computer, run a local web server in this folder, for example `python3 -m http.server`, and open the address that the server shows.

To report a problem with Saber Wallet, open an issue in this repository.
